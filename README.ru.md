# RCynQ

**Remote Code sYNchronization, Quick: доставка кода на удалённую машину без коммита.**

[English version](README.md) · [Страница проекта](https://depthrel.github.io/RCynQ/)

Репозиторий лежит в закрытой сети. Ваш компьютер — в другом месте, и напрямую они друг друга не видят. RCynQ связывает их напрямую или через узел Relay, доступный обоим. После этого вы правите файлы у себя и одной кнопкой доставляете их — или получаете свежую версию.

```
 Workstation                 Relay                     Origin
 здесь вы       ─────────▶  пропускает трафик, ─────▶  здесь лежат
 работаете      ◀─────────  прочитать не может ◀─────  репозитории
```

## Что вы получаете

- **Pull.** Одна кнопка приносит текущую ветку с узла Origin, в том числе в пустую папку.
- **Отправка изменений.** Незакоммиченные правки уходят патчем в любую сторону. Конфликты показаны по файлам, их можно слить средствами Git.
- **Через Relay.** Поставьте на пути один или несколько узлов Relay: облачную виртуалку, bastion-хост, офисный шлюз. Каждый пробрасывает SSH-порт и больше ничего.
- **Несколько репозиториев.** Зарегистрируйте на узле Origin сколько нужно и переключайтесь между ними с любой стороны, без перезапуска. Репозиторий, которого на узле Workstation ещё нет, скачивается в выбранную вами папку.
- **Репозиторий на Origin только читается.** RCynQ не записывает в него ни remote, ни ссылок, ни настроек, ни коммитов. Меняются там только файлы, которые вы сами отправили.
- **Посреднику не нужно доверять.** Узел Relay пересылает зашифрованный трафик и не видит содержимого. Патчи подписаны, защищены от повторов и применяются целиком или никак.
- **Работает там, где SSH-сервер запрещён.** Конечный узел принимает подключения либо через свой SSH-сервер, либо на собственном TLS-порту.
- **Портативность.** Настройки, ключи и данные лежат в папке программы. Windows, Linux и macOS; приложение с окном и командная строка (`rcynq`).

## Установка

| Система | Пакет |
|---|---|
| Windows | `RCynQ-<версия>-setup.exe` (для текущего пользователя, без прав администратора) или портативный `RCynQ-<версия>-win-x64.zip` |
| Debian, Ubuntu | `RCynQ-<версия>-linux-x64.deb` (`sudo apt install ./RCynQ-<версия>-linux-x64.deb`) или портативный `.tar.gz` |
| macOS | `RCynQ-<версия>-osx-arm64.tar.gz` (Apple silicon) или `osx-x64` (Intel) |

## Сборка

Нужны .NET SDK версии из `global.json` и Git.

```
dotnet build RCynQ.slnx
dotnet test RCynQ.slnx
```
